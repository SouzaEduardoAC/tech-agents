# V3 Hybrid Architecture Specification & Branch Initialization
- **Branch Created**: `feat/v3-playbooks-and-checks-architecture` branched from latest `main` (commit `1f58eff`, release `v2.3.0`). Configured for automatic major version bump (`v3.0.0`) via release-please.
- **Architectural Brainstorming & Specification**:
	- Confronted the fundamental reality of the v2 codebase: recognized that static persona folders and prompt compilation are essentially simulated roleplay ("prompt cosplay"), not autonomous agents.
	- Designed the **V3 Hybrid Architecture**: transforming the platform into an **Agentic Engineering Harness** built on four decoupled primitives:
		1. **Playbooks**: Deterministic DAG workflows (`playbooks/*.yaml`) defining stages from discovery to PR.
		2. **Cognitive Lenses**: Concentrated 2-3 sentence domain stances (`lenses/*.md`) replacing 500-line persona BIOS bloat and eliminating up to 70% of context noise.
		3. **Toolboxes**: Step-scoped capability toolsets adhering to the principle of least privilege.
		4. **Checks & Gates**: Deterministic local test/lint exit-code executions (Hard Checks) and machine-enforced approval gates (`.squad-state-[branch].json`) that physically prevent hallucinated phase progression.
	- **Artifacts Created**:
		- Canonical Logseq Graph Specification: [[v3-architecture-spec]] in `docs/pages/v3-architecture-spec.md`.
		- Root Developer Reference: `V3_ARCHITECTURE_SPEC.md`.
		- Registry Update: Registered in `docs/pages/registry.md`.

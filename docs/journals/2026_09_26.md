# V3 Hardening: Feature Slugging, Soft Check Enforcement & Polyglot Check Runners
- **Feature Slug & Variable Interpolation**:
	- Added `slugify` to `engine/state_manager.js` converting goals/feature names into deterministic kebab-case slugs (max 40 chars).
	- Implemented recursive variable interpolation (`interpolateVariables`) in `engine/prompt_compiler.js` resolving `{{args}}`, `{{feature}}`, and `{{goal}}` dynamically across step prompts, input artifacts, and output artifacts.
	- Updated `playbook_start` MCP tool in `index.js` to accept `feature` parameter and report resolved feature slug.

- **Prompt Assembly Directives & Guidance**:
	- Enriched step prompts in `compileStepPrompt` with:
		- `## Step Objectives & Instructions`: Clear mandate and task description.
		- `## Required Output Artifact`: Explicit target file path and instructions to create it.
		- `## Mandatory Human Approval Checkpoint`: Highlighting when the step requires a human gate approval.
		- `## Dynamic Project Stack Guidance`: Restored multi-module / monorepo stack detection (`getDynamicKnowledge`) for architecture and implementation lenses.

- **Deterministic Soft Check & JSON Schema Enforcement**:
	- Implemented `extractStructuredData` and `runSoftChecks` in `engine/check_runner.js` supporting YAML frontmatter, JSON code blocks, YAML code blocks, and markdown section headers.
	- Enforced in `engine/playbook_runner.js`: `advanceStep` now verifies that if a step defines `soft_checks` or `output_artifact`, the artifact must exist on disk and pass JSON schema validation before advancing.

- **Standalone Polyglot Hard Check Scripts**:
	- Created `checks/hard/standard_test.sh`: Portable bash script detecting project test runners (npm test, cargo test, go test, flutter test, dart test, pytest, python3 unittest, mvn test, ./gradlew test, dotnet test) and executing with exit code propagation.
	- Created `checks/hard/standard_lint.sh`: Portable bash script detecting linters (npm run lint, eslint, cargo clippy, golangci-lint, go vet, flutter analyze, dart analyze, ruff, flake8, dotnet format).
	- Tested with mock environments in `test/v3-hard-checks-scripts-test.js` and confirmed 100% test pass rate across all test suites.

# The Council Agent

The **Council** is a specialized consensus and synthesis agent designed to simulate structured dialectical friction. It evaluates user feature requests through five distinct simulated personas (Product Owner, Strategic Researcher, Systems Architect, Automata Workflow Engineer, Privacy Auditor) in a single context, ensuring ideas are stress-tested against business value, empirical validity, system performance, workflow automation, and legal safety before implementation.

---

## 🛠 Command Library

### 1. `/council:debate "your user request"`
- **Objective:** Initiates a 5-perspective dialectical debate on a user feature proposal.
- **Output:** Outputs a structured `🏛 Council Debate Report` containing the pitch, reality check, architectural critiques, automation blueprint, regulatory guardrail, rebuttals, and a final balanced production compromise specification with a technical matrix.
